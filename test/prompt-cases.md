# Ariadne Prompt 回归样例

这些案例用于人工检查初始化与归类 Prompt。每次 Prompt 规则发生变化时，至少逐项核对一次。

## 案例

1. 单一产品想法：我想做一个可以在对话中辅助长期研究的 Ariadne 工具。
2. 已有论文五段大纲：研究问题、理论机制、数据、识别策略、稳健性检验。
3. 三个租房区域的选择：Bloomsbury、Shoreditch、Wembley，各自已有预算和通勤信息。
4. 商品价格上涨原因诊断：铜价近期上涨，需要区分供给、需求、库存、美元和资金因素。
5. 自由创意联想：围绕“城市里的安静角落”自由发散。
6. 文献 × 主题多对多分类：同一篇文献同时涉及制度、协作与激励。
7. 简单改写请求：把这句话改得更自然。

## 人工检查

- 一级节点是否使用同一逻辑维度。
- 用户已有轮廓是否保留。
- 新一级方向是否真正独立。
- 子节点是否回答父节点的问题。
- 是否过早进入执行。
- 是否为了完整度无意义补满方向。
- 简单改写请求是否保持 Ariadne 关闭或不建图。
